## تغییرات نسخه‌ی v0.8.3

### تغییر نام تانل‌ها و سرورها
- هر تانل و هر سرور حالا یک **نام نمایشی** دارد که هر وقت بخواهید، به هر زبانی، عوض می‌شود. مثلاً به‌جای `t1` بنویسید «6to4 آلمان اصلی» و به‌جای `germany` بنویسید «آلمان هتزنر».
- نام قبلی **شناسه**ی تانل یا سرور می‌ماند. رابط شبکه (`nt-t1`)، کلیدها، پورت‌ها و دستورهای اتصال همه با همان شناسه کار می‌کنند. پس تغییر نام تانل را قطع یا دوباره‌سازی نمی‌کند و روی تانل‌هایی که الان کار می‌کنند هیچ اثری ندارد.
- **در پنل:**
  - تانل: کارت تانل را باز کنید و دکمه‌ی مداد کنار نام را بزنید.
  - سرور مقصد: دکمه‌ی مداد کنار نامش در صفحه‌ی «سرورها».
  - همین سرور: «تنظیمات» ← «این سرور» ← «نام نمایشی».
- نام نمایشی همه‌جا دیده می‌شود: داشبورد، تانل‌ها، آمار، پورت‌ها، تست سرعت، هشدارها و منوی ترمینال. شناسه هم در جزئیات تانل، کارت سرور و منوی ترمینال کنار نام نمایشی نوشته شده.
- نام نمایشی هر تانل به سرور مقصد هم فرستاده می‌شود و پنل آن سرور هم همان نام را نشان می‌دهد.
- خالی گذاشتن نام نمایشی دوباره خود شناسه را نشان می‌دهد. حداکثر ۴۰ حرف.
- **در خط فرمان:**

  ```bash
  sudo neotunnel tunnel rename t1 "6to4 آلمان اصلی"
  sudo neotunnel peer rename germany "آلمان هتزنر"
  sudo neotunnel node --label "ایران تهران"
  ```

  `tunnel list` و `peer list` نام نمایشی را کنار شناسه نشان می‌دهند.

### به‌روزرسانی
- سرور اصلی را به‌روز کنید تا بتوانید نام‌ها را عوض کنید. سرورهای مقصدی که هنوز به‌روز نشده‌اند بدون مشکل کار می‌کنند و فقط نام نمایشی را نمی‌بینند.
