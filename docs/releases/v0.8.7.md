## تغییرات نسخه‌ی v0.8.7

### پورت‌ها با حذف تانل اصلی روی پشتیبان می‌مانند
- قبلاً با حذف یک تانل، فورواردهای آن هم حذف می‌شدند، حتی اگر تانل پشتیبان داشتند.
- حالا اگر تانل اصلی یک پورت حذف شود و پشتیبانش بماند، پورت روی پشتیبان می‌ماند. پشتیبان تانل اصلی آن پورت می‌شود و تنظیمات پورت (پورت مقصد، حالت IP کاربر) دست نمی‌خورد.
- مثلاً پورت 10400 با «آلمان ۱» به‌عنوان تانل اصلی و «آلمان ۲» به‌عنوان پشتیبان: با حذف «آلمان ۱»، پورت 10400 روی «آلمان ۲» کار می‌کند.
- یک پورت فقط وقتی حذف می‌شود که هم تانل اصلی و هم پشتیبانش حذف شده باشند.
- پنجره‌ی تأیید حذف تانل می‌گوید کدام پورت‌ها به کدام پشتیبان منتقل می‌شوند.

### به‌روزرسانی
- فقط سرور اصلی را به‌روز کنید: از دکمه‌ی به‌روزرسانی پنل یا `sudo neotunnel update`.
